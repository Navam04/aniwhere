# Security

Aniwhere is meant to be reachable only over your tailnet, with access limited to the Tailscale logins you allow.
If you find a way around that, or any other security problem, please don't open a public issue. Report it privately
through GitHub's [private vulnerability reporting](https://github.com/Navam04/aniwhere/security/advisories/new).

Fixes go into the latest release only, so keep your install up to date.
